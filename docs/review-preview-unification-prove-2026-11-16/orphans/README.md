# Ricontrollo delle orfane

`refresh.py.txt` legge il repository e scrive soltanto in `/tmp/review-orphans-refresh`. Dopo l'esecuzione gli output testuali sono stati copiati qui. `table.json` contiene le 22 schede, `*.rg.txt` i comandi e le occorrenze, `graph-module-context.json` descrizioni e relazioni nei due versi, `sourcehash-*.json` gli hash dei file realmente controllati. `report.md` è l'output del riproduttore; il rapporto principale aggiunge il collegamento a queste prove.

Le cinque candidate private/locali sono distinte dalle diciassette API pubbliche. Nessuna funzione è stata rimossa e non è dimostrata l'assenza di consumatori esterni o futuri.
