Come tenere aggiornata questa vista
Per controllare e aggiornare lo schema all’apertura, avviare python3 tools/open_architecture.py: Python legge i sorgenti e JavaScript mostra avanzamento e risultato nel browser locale. Anche la build CMake standard aggiorna automaticamente grafo e HTML quando cambiano sorgenti o configurazione; dopo il link viene aggiornata anche compilando il solo target forgecad. Se questa pagina è già aperta, ricaricarla. Le descrizioni curate delle responsabilità restano da rivedere quando cambia il significato di un modulo. Istruzione permanente in AGENTS.md.
Aggiornamento esplicito: cmake --build build-linux --target forgecad_architecture
Controllo rapido senza libclang: python3 tools/generate_architecture.py --check
